# mac-mini-sidecar-selfcheck · 无头 Mac mini + iPad 随航当屏 · 免费自检

把 Mac mini 当主机用（不接显示器）的人都会撞上同一件事：**macOS 的随航必须先检测到一块显示器，才肯把画面投给 iPad**。不接屏，mini 就是一块砖——连不上，也看不见。

这个仓库放的是随航套装里的**免费自检脚本**：一键检查你的机器满不满意"无头 + 随航"的全部条件，跑一遍就知道能不能用，**先自检，再决定要不要折腾**。

> 它**只读检查**，不安装任何东西、不修改系统设置。

## 快速开始

```bash
git clone https://github.com/luming-youyou/mac-mini-sidecar-selfcheck.git
cd mac-mini-sidecar-selfcheck
```

然后 **右键** 点击 `1-自检.command` → 选「打开」（首次运行 macOS 会拦双击，右键打开是绕开 Gatekeeper 的正规姿势）。

按提示看结果即可：

- 全部 `[通过]` → 你的机器一定能用
- 有 `[不通过]` → 先别买，把问题解决掉再跑一遍

## 它检查什么

| 项目 | 要求 |
|---|---|
| macOS 版本 | ≥ 14 |
| 芯片 | Apple Silicon（M 系列） |
| FileVault | 必须关闭（无头开机会卡在解锁界面，这是 macOS 机制，绕不过） |
| 自动登录 | 建议开启（不开也能用：开机后盲输密码回车即可） |
| 显示输出 / 远程登录 | 首次安装需临时接一次屏；远程登录仅 iPad 快捷指令遥控需要（可选） |
| iPad 型号识别 | 决定随航分辨率能否 1:1 对齐（识别不到也能用，退通用分辨率） |

## 实现思路（给想自己折腾的人）

核心是 macOS 的 `CGVirtualDisplay` 私有 API：建一块虚拟屏当"锚点"，让系统一直以为有显示器在，随航就肯接 iPad。

完整方案的做法大致是：

- 虚拟屏分辨率与 iPad 机型对齐（11 寸 iPad Pro 是 1194×834@2x），做到 1 像素对 1 像素，不缩放不糊
- 用 `launchd` 每 12 秒巡检：无物理显示器 → 建虚拟屏 + 触发随航 + `caffeinate` 防睡眠；有物理显示器 → 自动退出让位、销毁虚拟屏
- iPad 断线自动重连；另有 `on / off / status` 三个命令兜底，可配合 iPad 快捷指令走 SSH 切换

## 实测数据（Mac mini + iPad Pro 11"，实测 2026-10）

- 拔掉显示器 → iPad 亮起桌面：**约 7 秒**（多轮稳定）
- 断线自愈：**5–16 秒**，多数落在 7 秒内
- 常驻内存：**约 7 MB**（三个小进程）
- 插回显示器：工具自动让位，两屏不打架
- 重启后开机自启，全程无需任何操作

## 硬限制（先说清，免得白折腾）

1. **必须关闭 FileVault**——无头开机要自动登录，FileVault 开着会卡在解锁界面，绕不过去
2. 只支持 **Apple Silicon + macOS 14 及以上**
3. iPad 端触控有版本门槛：单指/双指操作需要 **macOS 27 + iPadOS 27** 同时满足；版本不够就用 Apple Pencil 或蓝牙键鼠
4. 必须同一网络；安卓热点默认开"客户端隔离"，要手动关掉（iPhone 热点没这问题）
